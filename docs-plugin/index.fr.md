# Plugin TBk — Documentation technique

Bienvenue dans la **documentation technique** du plugin TBk (QGIS) — installation, utilisation, outils, workflows et jeux de données utilisés.

!!! info "Prototype"
    Ceci est le prototype de la documentation technique, séparée de la [documentation de contenu](https://HAFL-WWI.github.io/TBk-Docs/tbk/) (contenu des cartes des peuplements, légendes, interprétation). Les deux documentations sont construites indépendamment sous forme de sites/PDF distincts.

    Le contenu ci-dessous correspond à l'état de développement de la branche `dev/modularized` du [dépôt du plugin TBk](https://github.com/HAFL-WWI/TBk) (deviendra prochainement `main`).

## Structure de cette documentation

- **[Installation](installation.md)** — prérequis, installation du plugin dans QGIS
- **[Utilisation](anwendung.md)** — utilisation de base du plugin
- **[Workflows](workflows.md)** — déroulements typiques, étape par étape
- **[Outils](tools.md)** — aperçu des différents outils/algorithmes
- **[Données](datensaetze.md)** — données d'entrée requises/prises en charge
