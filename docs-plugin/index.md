# TBk-Plugin — Technische Dokumentation

Willkommen bei der **technischen Dokumentation** des TBk-Plugins (QGIS) — Installation, Anwendung, Tools, Workflows und die verwendeten Datensätze.

!!! info "Prototyp"
    Dies ist der Prototyp der technischen Dokumentation, getrennt von der [inhaltlichen Dokumentation](https://HAFL-WWI.github.io/TBk-Docs/tbk/) (Bestandeskarten-Inhalte, Legenden, Interpretation). Beide Dokumentationen werden unabhängig voneinander als eigene Seiten/PDFs gebaut.

    Die Inhalte hier beziehen sich auf den Entwicklungsstand des Branches `dev/modularized` im [TBk-Plugin-Repository](https://github.com/HAFL-WWI/TBk) (wird in Kürze zu `main`).

## Struktur dieser Dokumentation

- **[Installation](installation.md)** — Voraussetzungen, Plugin-Installation in QGIS
- **[Anwendung](anwendung.md)** — Grundlegende Bedienung des Plugins
- **[Workflows](workflows.md)** — Typische Arbeitsabläufe Schritt für Schritt
- **[Tools](tools.md)** — Übersicht der einzelnen Werkzeuge/Algorithmen
- **[Datensätze](datensaetze.md)** — Benötigte/unterstützte Eingabedaten
