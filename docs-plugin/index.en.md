# TBk Plugin — Technical Documentation

Welcome to the **technical documentation** of the TBk plugin (QGIS) — installation, usage, tools, workflows and the datasets involved.

!!! info "Prototype"
    This is the prototype of the technical documentation, kept separate from the [content documentation](https://HAFL-WWI.github.io/TBk-Docs/tbk/) (stand map contents, legends, interpretation). Both documentations are built independently as separate sites/PDFs.

    The content here reflects the state of the `dev/modularized` branch in the [TBk plugin repository](https://github.com/HAFL-WWI/TBk) (will soon become `main`).

## Structure of this documentation

- **[Installation](installation.md)** — requirements, installing the plugin in QGIS
- **[Usage](anwendung.md)** — basic operation of the plugin
- **[Workflows](workflows.md)** — typical workflows step by step
- **[Tools](tools.md)** — overview of the individual tools/algorithms
- **[Datasets](datensaetze.md)** — required/supported input data
